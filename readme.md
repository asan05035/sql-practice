# 🗄️ SQL Practice — Data With Baraa

My personal practice repository for the **Data With Baraa SQL Course**, covering fundamental syntax, complex querying, database objects, and performance optimization.

## 📌 Syllabus & Topics Covered

- **Basics:** DDL (`CREATE`, `ALTER`), DML (`INSERT`, `UPDATE`, `DELETE`), Filtering (`WHERE`, `HAVING`)
- **Functions:** Row-level string/date operations, `CASE` statements
- **Joins & Sets:** `INNER`, `LEFT`, `RIGHT`, `FULL OUTER`, `UNION`, `INTERSECT`
- **Subqueries & CTEs:** Correlated subqueries, standard & recursive CTEs
- **Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LAG()`, `LEAD()`, running totals
- **Objects & Temp Storage:** Views, CTAS, Temporary Tables
- **Programmability:** Stored Procedures, Triggers
- **Optimization:** Clustered/Non-Clustered Indexes, Table Partitioning
